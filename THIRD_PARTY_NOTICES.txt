AVATAR 3D

The virtual presenter is a synthetic 3D character, not a video of a person.

Asset: Casual Woman, rigged version
Author/source: Grab3D
https://grab3d.com/models/characters/woman/
https://grab3d.com/dl/woman-rigged/woman-rigged.glb

The source publisher expressly dedicates the model and textures to CC0 1.0:
https://grab3d.com/dl/woman/LICENSE.txt
https://creativecommons.org/publicdomain/zero/1.0/

Source disclosure: AI-assisted. Grab3D generated the base mesh and textures
with Meshy, then cleaned up, scaled, textured and checked them in Blender.
The reference screenshot supplied by the user is not included in this model
or in the published site.

Changes for this catalog: cropped unseen lower-body geometry, removed walk
and run animations, added 20 custom facial poses for Spanish articulation,
blinks and expression, gzip compression, studio lighting and a rendered poster.
The source file's SHA-256 is recorded in the GLB asset metadata.
The preprocessing script is scripts/prepare-avatar.mjs.

Created using Blender and MPFB / MakeHuman.
Changes for this catalog: resized textures, reduced geometry precision,
removed unused morph targets and animations, gzip compression, and a
rendered preview image. Runtime changes include softer eyebrow materials,
reflective eyes, a plain navy top, portrait lighting and new facial motion.
The original TalkingHead runtime is not included.
